Install

Use APT after verifying trust.

The archive key is a trust anchor. Verify its published primary fingerprint against the project documentation before installing the keyring and adding this repository to your APT sources.

sudo apt-get update
sudo apt-get install pantheon-local-tools

Do not skip fingerprint verification. The complete APT setup guide owns the current keyring, Signed-By, rotation, and recovery procedure.
